# Unused Components

This folder contains components that are no longer on an active render path.

Do not edit these files for user-facing changes unless you first restore and
wire them into the app. The active homepage currently renders through:

```text
app/page.tsx
components/lake-economy/LakeEconomyHome.jsx
components/lake-economy/runtime.js
components/lake-economy/lake-economy.css
```

`PapersPanel.jsx` was moved here because the live Papers panel is generated by
`contentForMode("papers")` in `components/lake-economy/runtime.js`.
